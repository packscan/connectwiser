Printer setup help

Install and run Zebra Browser Print on the packing computer. If Discover shows "Failed to fetch" on app.packscan.shop, click the padlock in Chrome → Site settings → Permissions → allow "Local network access" or "Apps on your local network," then reload. PackScan uses Browser Print's local HTTP service, so no localhost certificate approval is needed.

For browser printing, select the 4×6 printer, turn off “Fit to page,” and use 100% scale. Setting it as the Windows default avoids choosing it each time.
